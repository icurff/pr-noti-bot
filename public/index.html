🧪 Mô Phỏng Sự Kiện GitHub Webhook

Kích hoạt các kịch bản mẫu trực tiếp vào Discord Bot để kiểm tra giao diện và màu sắc Embed.

💡 Cơ chế chống spam của RepoRelay: "Một PR = Một Embed + Một Thread".
Nếu PR đã tồn tại trên kênh Discord (như PR #101), bot sẽ chỉnh sửa trực tiếp tin nhắn cũ. Để bot bắn một tin nhắn Embed mới tinh màu Emerald kèm Diff Bar xuống đáy kênh, hãy tăng số PR lên (ví dụ: #103, #104...) rồi bấm "Gửi Sự Kiện Open"!
Pull Request

1. Tạo PR Mới (Open)

Gửi sự kiện mở Pull Request với số PR đang chọn. Bot sẽ tạo một Embed màu Emerald kèm thanh đo trực quan `🟩🟩🟩🟩🟥` và mở một Thread Discord riêng.

Workflow Run

2. CI Passed (Thành Công)

Cập nhật kết quả workflow kiểm thử CI thành công. Cập nhật Embed chính và đăng vào Thread kèm 1 GIF ăn mừng ngẫu nhiên.

Workflow Run

3. CI Failed (Thất Bại)

Mô phỏng lỗi biên dịch hoặc rớt unit test. Bot đổi trạng thái CI thành màu Đỏ và đính kèm GIF sự cố hài hước (This is fine dog...).

Review

4. Review Approved

Mô phỏng reviewer phê duyệt code. Cập nhật danh sách review trên Embed chính và gửi GIF gật đầu LGTM vào luồng thảo luận.

Review

5. Review Changes Requested

Mô phỏng reviewer yêu cầu chỉnh sửa. Đổi trạng thái Review sang màu Vàng Cam và gửi GIF soi kính lúp tìm bug vào luồng.

Pull Request

6. Merge PR (Hoàn Tất)

Đóng và merge PR vào nhánh chính. Embed chính chuyển sang màu Tím Hoàng Gia `[MERGED]` và gắn Banner pháo hoa ăn mừng.
